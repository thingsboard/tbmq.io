export const kafkaSecretCmd = (namespace) => `kubectl create secret generic tbmq-kafka-credentials -n ${namespace} \\
  --from-literal=kafka-config="security.protocol:SASL_SSL;sasl.mechanism:PLAIN;sasl.jaas.config:org.apache.kafka.common.security.plain.PlainLoginModule required username=\\"tbmq-kafka-client@$GCP_PROJECT.iam.gserviceaccount.com\\" password=\\"$(base64 -w0 ~/tbmq-kafka-client-key.json)\\"\\\\;" \\
  -o yaml --dry-run=client | kubectl apply -f -`;

Create the `tbmq-kafka-credentials` Secret from the Kafka service account key. It sets SASL over TLS, the PLAIN
mechanism, the service account as the username, and the Base64-encoded key as the password. The same command replaces
the key when you rotate it:

<Code code={kafkaSecretCmd(props.namespace)} lang="bash" />

`base64 -w0` is the Linux syntax; on macOS, use `base64 -i ~/tbmq-kafka-client-key.json`. After you replace the key
of a running deployment, restart the pods to pick it up:

<Code code={props.restartCmd} lang="bash" />
