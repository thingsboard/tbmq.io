## Add user

1. Click **Users** in the left-hand menu, then click the **plus icon**.
2. Provide the user's email address (must be unique). First name, last name, and description are optional. Click **Add**.

<ShowFor product={props.product} show={[Products.TBMQ_PE]}>
In TBMQ PE, the dialog also contains a **Role** selector — choose **Administrator** or **Viewer** for the new user.
</ShowFor>

All new users are created with the default password `sysadmin`. Users are prompted to change it on first login.

## Edit user

1. Locate the user in the **Users** table and click on the row.
2. Click the **Toggle edit mode** button.
3. Modify the first name, last name, or description, then click **Apply changes**.

<ShowFor product={props.product} show={[Products.TBMQ_PE]}>
In TBMQ PE, the user's **Role** can be changed the same way — except your own, which is always read-only.
</ShowFor>

## Delete user

A logged-in user can delete other users but not themselves.

1. Find the user in the **Users** table and click on the row.
2. Click the **Delete user** button and confirm by selecting **Yes**.

## Login as another user

Administrators can log in as other users without requiring their credentials.
The feature is controlled by the `SECURITY_USER_TOKEN_ACCESS_ENABLED` environment variable (default `true`); when disabled, the **Login** button is hidden.

1. Find the user in the **Users** table.
2. Click the **Login** button in the corresponding row.

<ShowFor product={props.product} show={[Products.TBMQ_PE]}>
<ConditionalHeading level={2} id="user-created-via-oauth-20" showFor="mqtt-broker-pe">User created via OAuth 2.0</ConditionalHeading>

If a user signs in using <DocLink product={props.product} path="security/oauth-2-support/#basic-mapper">OAuth 2.0</DocLink> while the **Allow user creation** option is enabled,
the user account is automatically created without a password.
These users can continue using SSO to log in.

To enable username/password login, go to **Account → Security** and <DocLink product={props.product} path="user-guide/ui/settings/#change-password">set a new password</DocLink>.
Leave the **Current password** field empty when setting the password for the first time.

The user details page also includes an **Audit logs** tab listing the <DocLink product={props.product} path="security/audit-log">audit log</DocLink> entries related to the user.

<Aside type="caution">
  Adding, editing, deleting, and logging in as users are available only to users with administrator rights — Viewers
  get a read-only view of the Users page. The REST API enforces the same rule: reading users requires the `READ`
  permission, saving them requires `WRITE`, and deleting requires `DELETE`. See
  <DocLink product={props.product} path="security/rbac">Roles and permissions</DocLink>.
</Aside>
