The product roadmap covers only main features and does not include minor improvements or bug fixes.

All features planned for the Community Edition are also included in the Professional Edition.

- **Message Filtering and Transformation**

  Filters MQTT messages by topic, payload content, or message properties and reshapes their payloads as they
  flow through the broker. Downstream systems receive only the data they need, in the format they expect,
  without an extra processing service in between.

- **Expanded Third-Party Service Integrations**

  Delivers new pre-built integrations with major external services (e.g., specific databases, cloud services,
  and enterprise applications). This accelerates development and simplifies connecting TBMQ data directly
  into enterprise workflows.

- **Cluster Monitoring Page**

  Adds a Management Console page that shows the whole cluster in one view: every broker node with its status and
  load. Operators can spot an unhealthy or overloaded node at a glance instead of checking each node separately.

- **Connection Rate Limiting**

  Limits how often clients can open new connections, per client ID or per source IP address. This protects the
  cluster from reconnect storms and from clients that reconnect in a tight loop, alongside the existing publish
  rate limits.

- **Expanded Prometheus Metrics**

  Adds new Prometheus metrics, for example authentication results per provider, connected sessions per transport
  (TCP, SSL, WebSocket, secure WebSocket), incoming messages per QoS level, and the actor system's message backlog.
  This makes it easier to tell a failing authentication provider from bad client credentials, plan capacity, and
  detect overload before it affects clients.
