<ShowFor product={props.product} show={[Products.TBMQ]}>
**TBMQ** is an open-source MQTT broker built by the ThingsBoard team for large-scale IoT: scalable, fault-tolerant
and durable messaging for millions of MQTT 3.x and 5.0 clients. It runs as a masterless cluster — Apache Kafka carries
every message and state change between nodes, Redis (or Valkey) queues messages for persistent devices, and PostgreSQL
stores metadata — so capacity grows by adding nodes and no publish is acknowledged before it is persisted. Measured at
100M+ concurrent connections and 3M+ messages per second, and free under the Apache 2.0 license.
</ShowFor>

<ShowFor product={props.product} show={[Products.TBMQ_PE]}>
**TBMQ Professional Edition** is the commercial MQTT broker built by the ThingsBoard team for large-scale IoT:
scalable, fault-tolerant and durable messaging for millions of MQTT 3.x and 5.0 clients. It runs the same masterless,
Kafka-backed cluster as the Community Edition — measured at 100M+ concurrent connections and 3M+ messages per second —
and adds what production teams need on top: OAuth 2.0 single sign-on, role-based access control, audit logs, domain
management, white labeling and a managed Private Cloud.
</ShowFor>
