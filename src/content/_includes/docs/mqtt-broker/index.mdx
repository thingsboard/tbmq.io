TBMQ is an open-source MQTT broker for MQTT 3.1, 3.1.1 and 5.0, designed to run as a cluster of nodes that never
talk to each other directly: Apache Kafka carries every message, session and subscription change between them, Redis
(or Valkey) holds the message queues of persistent DEVICE clients, and PostgreSQL stores metadata. Capacity grows by
adding nodes, and a publish is acknowledged only once Kafka has persisted it. The Community Edition is free under the
Apache 2.0 license; the Professional Edition adds OAuth 2.0 single sign-on, role-based access control, audit logs,
white labeling and a managed Private Cloud.

This documentation follows that path from the first connection to a production cluster. Start with the public demo
broker below, then continue to the architecture, installation, security and client management sections.
